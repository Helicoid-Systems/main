# Independent deployment TLS trust contract, revision 1
Frozen coordinator contract for native client packages. This is transport trust, NOT account authentication, engine admission, enrollment or Deployment Verified.
Inputs are immutable deployment_id (nonempty bounded identity), canonical HTTPS origin (host + port; no credentials/path except slash/query/fragment), ONE deployment CA certificate as bounded DER (max64KiB), and an independently verified SHA-256 hex fingerprint of exactly those CA DER bytes. Trust is supplied by an operator/verified SSH bootstrap channel, NEVER learned from the HTTPS peer/health response. No TOFU or fallback to OS/browser roots. This package does not implement adoption UI or persist trust.
Validate CA/pin/URL before making any request. Only the configured origin may be addressed; refuse arbitrary absolute target URIs or relative traversal/scheme escapes. Authentication redirects are never followed, including same-origin redirects. HTTPS uses native maintained TLS, TLS1.2 minimum (1.3 preferred), valid chain anchored solely in pinned CA, valid server-auth EKU/hostname/dates. Online AIA/CA downloads are disabled. Invalid pin/chain/hostname/missing cert or unknown auth challenge cancels. No permissive certificate callback; pin matching alone does not replace certificate validation.
Expose a bounded cancelable HTTPS transport request seam for later v2 account integration. Production app mode and loopback development clients stay as currently wired; do not add a login/UI entry path. Reject negative/nonfinite bounds; per-operation deadline covers connection+headers+body; cap decoded body at64KiB by default, with absolutehardcap1MiB. Refuse redirects and non2xx responses; no cookies, credentials/proxy or cache adoption. Cleanup/disposal required. No bearer/token sourcecode/logging.
Prove actual TLS sockets with genuine generated CA/server certificates in TEST-ONLY fixtures or disposable processes. Positive pinned CA, foreign CA even when platform trust would otherwise allow, wrong DNS name, expired/nonserverauth cert, bad pin, HTTPS origin mismatch, redirect nofollow, bounded oversized/chunked body, cancellation/timeout, and disposal. No fixture pixels/identity/certificate enters normal app operation. State native Windows OS verification separately from cross-platform .NET-on-Mac proof. Do not claim enrollment/production ready.

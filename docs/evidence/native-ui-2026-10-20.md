## Packaged Mac observations

Observed through the actual arm64 development apps, without fixture launch flags:

- Normal Connect opens with the address field focused, no development address prefilled, and Connect unavailable without verified profile adoption.
- Set Up Server opens the two real read-only inspection routes. Copy states that installation is unavailable; no installer success or administrator collection is reachable.
- About shows the supplied role icon, actual version/build, general monitoring/assistance description, Source and Done. Escape returns to Connect.
- Command-comma opens Computer Settings; both missing permissions have accessible names/purposes and one Allow action; closing returns to status. No permission prompt was activated.

[About](native-ui-2026-10-20/manager-about.jpg), [Connect](native-ui-2026-10-20/manager-connect.jpg), [Computer permissions](native-ui-2026-10-20/computer-permissions.jpg), and [permission accessibility tree](native-ui-2026-10-20/computer-permissions-ax.txt) record these observations. Connect and Computer captures can appear as transformed window thumbnails; they are insufficient for full visual acceptance. About has a full-size capture. System keyboard navigation did not move focus to permission buttons with Tab; that scenario remains Not Verified rather than changing the user's OS preferences.

Light appearance, high contrast, text scaling, VoiceOver/Narrator, full keyboard navigation, populated inventory/viewer windows, minimum work areas, inactive appearance, installed permission revocation, and OS effects remain Not Verified. Fixture/model tests cannot establish any of these or real pixels.

# Managed assistance is ended by the operator or authorized IT

The earlier managed-device answer gives the authorized remote operator and IT explicit stop authority. Following the general-monitoring correction, these replace the teacher/student role names. The monitored-computer UI identifies who is controlling it and how to contact them. It has no user stop command in this managed mode. Expiry, revocation, desktop-session replacement, and security teardown still end access automatically. IT stop/recovery rights remain separate from screen observation. Future personal-device support needs its own consent and stop contract.

# Verification contract

Draft updated on 10 October 2026. These scenarios are required evidence, not tests already run. Each result records exact source/artifact versions, hardware/OS, account/device policy, steps, observations, command/log identifiers, and limitations. Synthetic fixtures can verify state logic; they cannot prove OS capture, permissions, input, installation, or performance.

## Required platform coverage

Mac manager to Windows endpoint, Windows manager to Windows endpoint, Mac manager to Mac endpoint, and Windows manager to Mac endpoint. Mac manager and endpoint checks include compatible Intel and Apple Silicon hardware. Exercise the supported OS/version matrix frozen by E04/E08, not an invented promise that all Intel models work.

A release claim states which combinations passed and which capability remains unsupported. An unavailable protected/pre-login desktop must be explicit. Windows Session 0 is not a substitute for an actual signed-in user worker.

D26 limits version 1 desktop monitoring to the computer's physical/primary console. Exercise console plus RDP/background users to prove exclusion, not to claim those sessions are supported. D27 requires local keyboard/mouse to remain enabled during control on every supported endpoint platform.

Partial checkpoints do not mark V39 Passed. Record checkpoint results separately while the overall scenario remains Not Run, Failed, or Blocked by Environment as applicable until the full scenario passes. Service health, a TCP probe, synthetic media, or a completed checklist alone cannot complete V39.

## Gate completion

A scenario passes only when its observable result has retained evidence. Record Not Run, Failed, Blocked by Environment, or Passed with an identifier; copying this table into a release checklist is not evidence.

Boundary tests should target actual server/endpoint/helper seams. UI fixtures alone cannot satisfy V02 through V04. A successful build cannot satisfy V09 through V15 or V26 through V31. A syntactically valid installer cannot satisfy occupied-host noninterference.

Numeric timing/resource checks use the frozen E06 measurement definitions, hardware, sample sizes, workload, percentiles, and failure policy. Until those are fixed and measured, budgets remain targets. Independent security review and a real pilot precede the full release.

V46–V51 are additions to the existing boundaries, not executed tests. V46/V49 accumulate S01 checkpoints and complete only after the later administration and all required write/effect boundaries are exercised. V47 completes with actual S09 cutover/recovery hosts. V48 and V50 must prove confirmed D29/D30 respectively; the user's answers do not replace runtime evidence. V51 has an early S01 Mac manager resource checkpoint and completes the full installed Mac support matrix through S04/S09. A source copy/hash match alone cannot pass native icon compilation, display, fallback, or update behavior.
